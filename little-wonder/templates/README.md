# قوالب المونتاج — Little Wonder

جاهزة لإعادة الاستخدام في كل حلقة (القالب موصوف في `../PRODUCTION_RULES.md` §٤ و§٦).

| الملف | الاستخدام |
|---|---|
| `INTRO_with_logo_and_names.mp4` | الأغنية الافتتاحية + الشعار مع فتح البوابة + أسماء الشخصيات (1280×720، 24fps) — أول مقطع بكل حلقة |
| `OUTRO_with_logo.mp4` | الأوترو + الشعار — آخر مقطع بكل حلقة |
| `assets/BalooBhaijaan2.ttf` | خط البطاقات والعناوين (Google Fonts, OFL) |
| `assets/logo_1000.png` · `assets/logo820.png` | الشعار مقصوص وجاهز (المصدر: `channel/title_transparent.png`) |
| `assets/cap2.png` | سطر "Full episode on the channel" للشورتس |
| `scripts/norm.sh` | توحيد أي لقطة: 1280×720 · 24fps · yuv420p · AAC 48k ستيريو |
| `scripts/xf.py` | تجميع الحلقة بانتقالات 6 فريمات (14 بعد الانترو وقبل الأوترو) مع حفظ الطول والتزامن |
| `scripts/mk.py` | صنع الشورتس العمودية (1080×1920) بالقالب الثابت |

> السكربتات مكتوبة لمسارات جلسة الحلقة الأولى — عدّل المسارات (`G=`، مسار الانترو/الأوترو، الخط) لمجلد الحلقة الجديدة قبل التشغيل.
