# مهارات خبير الدعاية والتسويق وإدارة السوشل ميديا

هذه المهارات هي الأساس اللي بنبني عليه عميل التسويق. تم اختيارها بالبحث عن طريق مهارة `find-skills`
(أمر `npx skills find`) في سجل المهارات المفتوح [skills.sh](https://skills.sh)، ثم فلترة النتائج حسب
عدد التثبيتات وسمعة المصدر.

## المصادر

| المصدر | الرخصة | النسخة المثبتة |
|---|---|---|
| [vercel-labs/skills](https://github.com/vercel-labs/skills) — `find-skills` | MIT | الفرع `main` بتاريخ 2026-10-06 |
| [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) — ٢٥ مهارة | MIT (`LICENSE.marketingskills`) | commit `dda3841` |

ملفات `evals/` حُذفت لأنها اختبارات خاصة بالمطوّر ولا تحتاجها المهارة وقت التشغيل.

## خريطة المهارات حسب دور العميل

| الدور | المهارات |
|---|---|
| البحث عن مهارات جديدة | `find-skills` |
| الأساس: هوية المنتج/القناة والجمهور | `product-marketing` (ابدأ فيها؛ باقي المهارات تقرأ ملف السياق اللي تطلعه)، `customer-research`، `competitor-profiling` |
| الاستراتيجية والتخطيط | `marketing-plan`، `content-strategy`، `marketing-ideas`، `marketing-council`، `launch` |
| إدارة حسابات السوشل ميديا | `social`، `community-marketing`، `marketing-loops` (مهام متكررة: يومي/أسبوعي) |
| الدعاية المدفوعة | `ads` (Meta/TikTok/Google/X)، `ad-creative` |
| الكتابة الإعلانية | `copywriting`، `copy-editing`، `marketing-psychology` |
| المحتوى البصري | `image`، `video` |
| الشراكات والانتشار | `influencer-marketing`، `co-marketing`، `public-relations` |
| واتساب والرسائل | `sms` (يشمل WhatsApp) |
| القياس والتحسين | `analytics`، `attribution`، `ab-testing` |

## مهارات مستبعدة

مهارات SaaS والمواقع من نفس المصدر ما ثبتناها لأنها خارج نطاق الدعاية والسوشل ميديا:
`paywalls`، `signup`، `onboarding`، `churn-prevention`، `pricing`، `revops`، `sales-enablement`،
`cold-email`، `prospecting`، `aso`، `schema`، `seo-audit`، `programmatic-seo`، `ai-seo`،
`site-architecture`، `popups`، `free-tools`، `directory-submissions`، `referrals`، `lead-magnets`،
`emails`، `offers`، `competitors`، `events`.
لو احتجنا أي وحدة منها نسحبها من نفس المستودع.
